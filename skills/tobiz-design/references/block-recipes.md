# Проверенные сценарии обычных блоков TOBIZ

Источник - тестовый проект `432879`: 20 страниц, 355 установленных блоков, 126 уникальных
`type_id`. Это библиотека решений, а не шаблон для слепого копирования контента. Перед изменением
всегда вызывай `tobiz_describe_block`, потому что одинаковый `type_id` может иметь несколько
вариантов значений.

## Общий рецепт

1. Выбери обычный блок по задаче, а не по демо-картинке.
2. Сохрани штатную структуру `values`, меняй только описанные поля и элементы массивов.
   Перед работой с незнакомым типом вызови `tobiz_block_controls(type_id=..., control_type="interactive")`.
3. Контейнер по умолчанию `1170px`; вертикальные поля `72-96px` desktop и `40-64px` mobile.
4. На странице используй один радиус, один стиль тени, одну систему иконок и одну CTA-палитру.
5. Переключатели `show_*`, `hide_*`, `*_link`, `*_popup`, `img_do` и `mode` считай поведением,
   а не декором. После их изменения обязательно проверяй публичную страницу.
6. Не подменяй штатную кнопку HTML, якорем или JavaScript. Формы, карточки и видео остаются
   редактируемыми в визуальном редакторе.

## Обложка

Подходящие типы: `153-157`, `159`, `258`, `259`, `3040`; товарные/карточные варианты - `130`,
`311`, `320`, `1154`, `1156`, `1258`.

- Desktop: один H1, краткий лид, одна главная CTA, максимум одна вторичная. Текстовая область
  480-680px, безопасная зона фотографии не перекрывает лицо, товар или строение.
- Mobile: фон проверяется отдельно; H1 32-42px, кнопка не уже удобной зоны касания, контакты и
  главное условие остаются в первом экране.
- Фон: `bg_mode=image`, `bg_size=cover`, `bg_position` подбирается по объекту. Затемнение обычно
  0.35-0.6, но контраст проверяется по реальному кадру.
- Не использовать: несколько равноправных офферов, мелкий текст поверх пестрого фото, пустую
  вторую колонку, декоративный Flex вместо готовой обложки.

## Каталог и услуги

Подходящие типы: `124`, `125`, `130`, `414`, `1130`, `1302`; для тарифов - `307-309`, `318`,
`319`, `1308`, `1318`.

- Базовый каталог: `show_title=1`, `show_descr=1`, `show_price=1` при известных ценах,
  `show_btns=1` или `show_btn=1`; 3 карточки в ряд для подробных услуг, 4 - для коротких товаров.
- Изображения имеют одинаковое соотношение сторон и масштаб. Для карточки товара используй
  штатное `img_do=product_card`; для заявки - штатный popup и `form1`.
- Кнопки формулируй по действию: «Забронировать», «Получить расчет», «Уточнить наличие».
- Mobile: одна карточка в ряд; две допустимы только при коротком названии и без длинной цены.
- Не использовать: цену «по запросу», если известна точная; разные высоты изображений; кнопки,
  добавленные в описание HTML; одновременно тяжелую тень, рамку и цветную подложку.

## Формы

Подходящие типы: `306`, `1121`, `1306`; формы внутри обложек и каталогов используют их штатные
`form1`, `btn1`, popup-поля.

- Короткая заявка: имя и телефон; email или комментарий добавляй только при реальной нужде.
- Заголовок описывает результат после отправки, кнопка - действие пользователя.
- Поля светлые, вводимый текст темный, placeholder заметно слабее текста. Согласие и политика
  доступны, но визуально не конкурируют с CTA.
- Desktop: ширина 380-520px. Mobile: 100% контейнера, поля не мельче 16px.
- Проверь: можно заполнить каждое поле, маска телефона не блокирует ввод, форма открывается из
  всех связанных CTA, адрес заявки правильный. Без прямой просьбы форму не отправляй.

## Отзывы

Подходящие типы: `117`, `118`, `125`, `130`, `149`, `307`, `320`, `1149`, `1418`, `3010`,
`3117`.

- Используй только подтвержденные отзывы. Сохраняй естественную лексику и конкретную ситуацию,
  не дописывай достижения за клиента.
- 3 карточки - для коротких отзывов; слайдер - при 5 и более; цитата - для одного сильного кейса.
- Фото человека ставь только когда оно принадлежит автору; иначе используй фото результата,
  логотип площадки или текстовый вариант без вымышленного портрета.
- Mobile: одна карточка или штатный слайдер, текст читается без внутренней прокрутки.

## Видео

Подходящие типы: `1159`, `1160`, `3050` и доступные проекту варианты из категории видео.

- Используй штатное поле видео и штатную обложку. Не вставляй самописный iframe, если блок умеет
  принять ссылку.
- Заголовок сообщает, что увидит зритель; описание - 1-2 предложения, без повторения заголовка.
- Для 2-4 роликов используй штатную сетку или несколько видео-блоков одного типа. Превью должны
  иметь одинаковое соотношение сторон.
- Desktop: ширина плеера соответствует контейнеру и соседней сетке. Mobile: видео не выходит за
  экран и сохраняет aspect ratio.

## Галерея

Подходящие типы: `138`, `139`, `143-148`, `310`, `313`, `315`, `1144-1147`, `1155`, `1157`,
`1800`, `1810`, `1820`.

- Выбери один режим: портфолио, интерьер, процесс или детали. Не смешивай случайные изображения.
- Превью имеют единый crop. Режим popup выбирается по задаче: квадратный только когда все кадры
  выдерживают квадрат; альбомный - для объектов и интерьеров; исходный - для документов.
- 6 или 9 изображений дают устойчивую сетку 3x2/3x3. Первый ряд содержит самые сильные кадры.
- Mobile: 1-2 колонки; popup закрывается и листается; подписи не накладываются на важную часть.

## Карта и контакты

Подходящие типы: `108`, `162`, `165`, `303`, `1002`.

- Адрес, телефон, email и мессенджеры берутся из подтвержденных данных. Телефон использует
  штатный кликабельный режим или `tel:` через предусмотренное поле ссылки.
- Карта занимает 55-70% ширины на desktop, контакты - остальное. Текстовая колонка имеет верхний
  внутренний отступ и визуально центрируется относительно карты.
- Mobile: сначала контакты и действие, затем карта; высота карты 300-420px.
- Фон отделяет блок от подвала, но не создает случайную декоративную полосу.

## Подвал

Подходящие типы: `101`, `109-113`, `119`, `3060`.

- Один основной телефон, если нет реальной причины показывать второй. Логотип, реквизиты, политика,
  навигация и соцсети включаются только при заполненных данных.
- Цвет подвала согласуется с логотипом; контраст ссылок и телефона проверяется отдельно.
- Desktop: 40-64px вертикальных полей. Mobile: колонки складываются, телефон и политика не
  обрезаются, мелкий текст не меньше 14px.

## Flex 1600

- Flex применяется не более чем в 30% видимых блоков страницы. Обычные `167` и `3010` в этот
  лимит не входят.
- Используй Flex для уникальной композиции, которой нет среди обычных блоков: сложная схема,
  асимметричный editorial-блок, интерактивная связка штатных элементов.
- Сохраняй `cache` и исходную структуру. Не заменяй элементы HTML-плашкой. Текст, изображение,
  кнопка, форма и видео должны оставаться отдельными штатными элементами.
- Для каждого элемента настрой `l/m/s/xs/xxs`; mobile - самостоятельная композиция, а не
  пропорционально уменьшенный desktop.
