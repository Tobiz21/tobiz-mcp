# Безопасность

## Сообщить о проблеме

Не публикуйте в GitHub Issues логины, пароли, cookie, токены, содержимое `.env`, адреса клиентских
проектов или снимки с персональными данными. Создайте Issue только с версией MCP, кодом ошибки и
обезличенным результатом `tobiz_diagnostics`.

Если для воспроизведения нужны секреты или клиентские данные, сначала запросите у владельца
репозитория безопасный канал связи. До его получения не передавайте эти данные.

## Безопасная установка

- Используйте отдельный тестовый проект TOBIZ.
- Включайте `TOBIZ_REQUIRE_PROJECT_ALLOWLIST=true`.
- Указывайте только разрешенные проекты в `TOBIZ_ALLOWED_PROJECT_IDS`.
- Вводите пароль через `tobiz-mcp-configure`, а не в сообщении ИИ и не в аргументах команды.
- Перед передачей установки запускайте `tobiz-mcp-selftest --release`.
