# Чек-лист выпуска

## Автоматически

- [ ] CI: все тесты прошли.
- [ ] CI: Docker-образ собран.
- [ ] `tobiz-mcp-selftest --release PAGE_ID --project PROJECT_ID` вернул код `0`.
- [ ] В JSON-отчете `release_ready=true` и `missing_features=[]`.

## Установка пользователя

- [ ] Конфигурация создана через `tobiz-mcp-configure`.
- [ ] `TOBIZ_REQUIRE_PROJECT_ALLOWLIST=true`.
- [ ] В `TOBIZ_ALLOWED_PROJECT_IDS` только проекты пользователя.
- [ ] `tobiz_onboarding_check` вернул `distribution_ready=true`.
- [ ] Пользователь предупрежден, что изменения параметров страницы, статей и товаров применяются сразу.

## Контрольный сайт

- [ ] Чтение страницы не создает ложный черновик.
- [ ] `tobiz_editor_roundtrip_check`: `editor_safe=true`, `would_save=false`.
- [ ] Перед первой записью создается резервная копия.
- [ ] Восстановление копии проверено на тестовом проекте.
- [ ] Desktop/mobile-аудит не содержит критических ошибок.
- [ ] Формы, попапы, меню, каталог, видео, статьи и товары проверены по используемому сценарию.

## Поддержка

- [ ] Пользователю доступна команда `tobiz_diagnostics`.
- [ ] Пользователь ознакомлен с `PRIVACY.md`.
- [ ] Для проблемы приложены версия MCP, код ошибки и обезличенный диагностический отчет.
